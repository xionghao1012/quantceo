# QuantCEO 用户手册

## 一、快速开始

### 1.1 注册与登录

1. 打开浏览器访问部署地址（默认 `http://localhost:4001`）
2. 点击右上角 **登录** 按钮
3. 如无账号，点击 **注册** 填写邮箱、密码、昵称
4. 登录后进入行情看板

### 1.2 界面布局

- **顶部导航**：搜索框 + 登录状态 + 通知铃铛
- **左侧菜单**：功能导航（OSS 功能默认可见，Pro 功能需 License 解锁）
- **主内容区**：根据选中菜单展示对应页面

## 二、功能导航（OSS 版）

### 📊 行情看板（个股列表）
- 全 A 股 5000+ 只股票实时行情
- 支持搜索股票代码/名称
- 列表含：代码、名称、现价、涨跌幅、成交量

### 📈 个股详情
- 多周期 K 线图（日/周/月）
- 技术指标叠加：MA5/10/20/60、MACD、RSI、布林带
- 基本面数据（市盈率、市净率等）
- 添加自选、查看信号

### 🔬 策略回测
- 选择股票 + 策略 + 时间范围
- 内置策略：MA5/20、MA10/60、标准 RSI、标准 MACD
- 输出指标：总收益率、年化收益、夏普比、最大回撤、胜率、交易次数
- 权益曲线可视化
- 策略排行榜：查看各策略在所有股票上的表现

### 📡 信号扫描
- 全市场多策略并发扫描
- 内置规则：金叉死叉、MACD 零轴穿越、RSI 超买超卖、布林带突破
- 支持自定义规则（阈值条件、均线交叉组合）
- 分页展示结果，按强度排序

### 📈 指标排行
- 8 大技术指标排名：RSI、涨跌幅、成交量比、MACD 信号、布林位置、均线多头、波动率、动量
- 支持日期选择、板块筛选（主板/创业板/科创板）
- 策略评分模式：超跌反弹、放量突破、底部启动等 6 种评分

### 🔍 选股筛选（Screener）
- 多条件组合筛选（AND 逻辑）
- 条件：价格、涨跌幅、成交量、换手率、振幅、RSI、MACD、均线交叉等
- 支持排序、分页

### 🌐 市场状态
- 大盘指数实时行情（上证、深证、创业板、科创板）
- 热门板块排行
- AI 市场状态分析（Pro）

### ⭐ 自选股
- 增删自选股（单个/批量）
- 多分组管理
- 查看自选股的实时行情

### 🎯 策略回测分析
- 各评分策略在所有股票上的表现汇总
- 策略推荐：根据历史表现推荐最佳策略
- 策略详情：查看单策略的交易记录和权益曲线

### 👤 个人中心
- 查看个人信息、使用统计
- 修改密码、更新资料
- 管理订阅计划

## 三、功能导航（Pro 版）

> Pro 功能需要设置 `LICENSE_KEY` 环境变量或购买付费计划。

### 🤖 AI 预测
- 单股预测：查看方向、置信度、目标价、止损价
- 批量预测：全市场扫描高置信度预测
- 历史预测评估：查看预测准确率统计
- 批量任务管理：查看运行中的预测任务

### 🤖 AI 精选推荐
- 每日精选：AI 多因子选股，展示推荐股票及评分
- 历史推荐记录：查看每日精选的历史表现
- 准确率统计：评估 AI 选股的历史准确率

### 💬 情绪分析
- **个股情绪**：AI 综合新闻、研报、公告、微博/微信热度打分
- **微博热度排行**：TOP 50 热门股票
- **微信热度排行**：TOP 50 公众号提及热度

### 📋 持仓管理
- 添加/编辑/删除持仓记录
- 自动止损止盈价格告警
- 持仓分析：每只持仓的盈亏、RSI 指标、距离止损止盈距离
- AI 调仓建议（独立页面 `/rebalance`）
- AI 持仓告警：分析持仓风险，生成卖出预警

### 📓 交易日志
- 记录每笔交易：方向、入场/出场价、数量、标签、策略、评分
- 交易统计：胜率、盈亏比、期望值、月度趋势
- 盈亏日历：按日/按月查看 P&L 分布

### 🛡️ 通知推送 & 通知中心
- 推送设置：开启/关闭各渠道（站内通知、微信 ServerChan）
- 推送触发：信号产生、每日精选、周报、价格告警、持仓预警
- 通知中心：查看历史通知，标记已读

### 🎯 推荐跟踪
- 跟踪 AI 每日精选的实盘表现
- 记录入场/出场操作
- 回测跟踪记录，查看总体收益

### 💡 AI 策略发现
- AI 自动发现交易策略
- 管理发现的策略列表
- 查看策略详情

### 🎯 策略优化
- 遗传算法参数优化
- 网格搜索参数空间
-  Walk-forward 分析
- 多策略对比
- 自定义策略管理

### 📊 Pro 选股筛选
- SQL 公式筛选
- 预置筛选模板
- 因子回测
- 行业对比
- 财务指标筛选

### ⚠️ 市场告警
- 实时价格告警订阅
- 放量突破检测
- 价格突破布林带检测
- WebSocket 实时推送

### 📊 盘中异动
- 盘中异常监控告警
- 手动触发异动检查

### 📉 风险管理
- 仓位计算（凯利公式/固定比例）
- 止损建议（ATR/波动率方法）
- VaR 计算（历史/参数法）
- 投资组合风险分析
- 最大回撤计算
- 风险热力图

### 🔑 API 管理
- 创建/删除 API Key
- 用于程序化接入

## 五、常见操作

### 搜索股票
页面右上角搜索框输入代码或名称拼音，下拉选择后跳转详情页。

### 添加自选
在个股详情页点击星形图标，或在行情列表悬停操作列添加。

### 运行回测
1. 进入「策略回测」页面
2. 选择股票（支持输入代码）
3. 选择策略（内置策略或自定义）
4. 设置时间范围、初始资金
5. 点击「运行回测」查看结果

### 查看信号
1. 进入「信号扫描」页面
2. 选择扫描范围（单股或全市场）
3. 选择规则（内置或自定义）
4. 点击「开始扫描」
5. 结果按强度排序，可查看详情
