# QuantCEO 商业计划书

## 一、项目概述

**QuantCEO** 是一个面向 A 股个人投资者的零代码量化交易平台，覆盖行情看板、策略回测、信号扫描、AI 预测、持仓管理等全链路。采用 OSS 开源引流 + Pro 付费变现的双轨商业模式，同时支持本地化部署销售给机构客户。

---

## 二、商业模式总览

```
开源版（MIT）─────────── 引流 ──→ 社区 → 品牌信任 → 用户基数
       ↓
  Pro SaaS ───────────── 变现 ──→ 月/年订阅费（个人用户）
       ↓
  本地化部署 ─────────── 变现 ──→ 一次性授权 + 年维护费（机构/企业）
```

三个收入引擎分层递进，服务于不同付费意愿的用户群体。

---

## 三、收入引擎一：开源引流（OSS）

### 3.1 策略

| 维度 | 说明 |
|------|------|
| **许可证** | MIT — 允许商业使用、修改、再分发 |
| **分发渠道** | GitHub 公开仓库、Docker Hub 镜像、技术社区（掘金/知乎/V2EX） |
| **OSS 功能** | 行情看板、策略回测、信号扫描、选股筛选、指标排行、市场状态、自选股、策略回测分析、个人中心 |
| **付费转化触点** | 限制每日扫描/回测次数（3次/天）、限定 20 只自选股、无 AI 功能、无持仓管理 |

### 3.2 获客路径

1. **SEO / 内容营销**：在知乎/公众号发布「零代码搭建量化交易系统」系列文章 → 引导 GitHub Star
2. **技术社区口碑**：GitHub Trending → 开发者自部署 → 发现功能限制 → 升级 Pro
3. **KOL 推广**：与财经/量化领域 KOL 合作，对比 QuantCEO 与聚宽/米筐的优劣势
4. **Docker 一键部署**：降低上手门槛，拉高 OSS 采用率
5. **高校合作**：作为金融工程/量化课程的教学工具

### 3.3 关键指标

| 指标 | 说明 |
|------|------|
| GitHub Stars | 品牌影响力的直接衡量 |
| Docker Pulls | 真实部署量 |
| OSS 日活用户 | 通过匿名 telemetry（需用户同意）统计 |
| OSS → Pro 转化率 | 目标: 3-5% |

## 五、收入引擎三：本地化部署（企业销售）

### 5.1 为什么需要本地化部署

- **私募/机构**：交易数据极其敏感，不允许上传第三方服务器
- **证券公司**：合规要求数据不出内网
- **高校/研究机构**：需要完整源码访问权限做二次开发
- **高净值个人**：需要专属定制服务

### 5.2 定价模型

| 套餐 | 定价 | 内容 |
|------|------|------|
| **Pro 自部署** | ¥9,800/年 | 完整 Pro 功能，单机部署，含 Docker Compose 编排 |
| **企业版** | ¥49,800/年 | 完整 Pro + Premium 功能 + 集群部署 + 监控告警 (Grafana/Prometheus) |
| **源码授权** | ¥198,000 | 全量源码 + 白标授权 + 专属定制 + 12 个月技术支持 |

### 5.3 本地化部署优势

| 对比项 | QuantCEO 自部署 | 聚宽/米筐 |
|--------|---------------|-----------|
| 数据隐私 | 完全本地，不出网 | 数据上传云端 |
| 定制化 | 全源码可改 | 有限 API |
| 一次购买 | 年付/买断 | SaaS 持续付费 |
| 离线运行 | 无需公网 | 必须联网 |
| 附加成本 | 仅服务器硬件 | 无 |

### 5.4 企业客户画像

| 客户类型 | 规模 | 预算 | 决策周期 |
|---------|------|------|---------|
| 小型私募（<1亿AUM） | 100-500 家 | ¥1-5 万/年 | 1-3 个月 |
| 量化工作室 | 50-200 家 | ¥2-10 万/年 | 1-2 个月 |
| 高校金融实验室 | 30-80 所 | ¥5-20 万/次 | 3-6 个月 |
| 证券营业部 | 200+ 营业部 | ¥3-10 万/年 | 3-6 个月 |

### 5.5 企业销售路径

1. **发布 OSS 版 → 企业技术负责人试用 → 内部 PoC → 采购签约**
2. **在 OSS 仓库中展示「企业版」入口，引导企业联系**
3. **参加量化/金融科技峰会（如 WorldQuant Challenge、QTF）**
4. **与云厂商合作（阿里云/腾讯云市场）上架「企业级量化平台」**

## 十、风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| OSS 被竞品直接复制 | 中 | 中 | MIT 协议鼓励生态，竞品难以复制 AI 和社区 |
| 数据源（搜狐/腾讯）停止服务 | 中 | 高 | 逐步切换到付费数据源（Wind/Choice）或自采 |
| 监管政策变化（量化交易限制） | 低 | 高 | 核心定位是辅助决策，不涉及自动化交易 |
| 付费转化率低于预期 | 中 | 高 | 调整定价、增加功能差异化、加强销售 |
| LLM 调用成本过高 | 低 | 中 | 缓存 + 降级到规则引擎 + 本地推理模型 |

## 十一、总结

QuantCEO 的商业模式核心是 **「开源圈地 + Pro 收割 + 部署赚钱」** 三层递进：

- **OSS** 解决信任和获客问题（零获客成本）
- **Pro SaaS** 解决个人用户支付能力（¥299/年，低频高转化）
- **本地化部署** 解决机构客户需求（¥49,800-198,000，低频高客单）

三者构成稳固的「漏斗式」收入模型。初期仅需 1-2 名开发者维护，盈亏平衡点极低（约 14 个年付 Pro 用户或 1 个企业客户），适合作为独立开发者/小团队的副业起步项目。
