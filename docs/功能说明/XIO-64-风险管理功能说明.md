# 风险管理功能说明

## 一、功能概述

风险管理模块为 Pro 用户提供完整的持仓风险分析、风险告警与风险控制建议服务，帮助用户量化投资组合风险并制定科学的仓位管理策略。

**页面路径**: `/risk-management`
**访问权限**: Pro 用户专用

---

## 二、功能范围

### 2.1 核心功能

| 功能 | 说明 |
|------|------|
| 仓位计算 | 凯利公式法、固定比例法、风险平价法 |
| 止损建议 | ATR 法、波动率法、均线支撑法、近低法 |
| VaR 计算 | 历史法、参数法（方差-协方差） |

| 最大回撤计算 | 历史最大回撤、回撤持续时间、恢复周期 |
| 风险热力图 | 市场高风险股票热力图 |

## 三、量化指标说明

### 3.1 VaR（Value at Risk）风险价值

**定义**: 在给定置信水平下，投资组合在特定时间内可能遭受的最大损失。

**计算公式**:

**历史法（Historical）**:
```
取历史收益率序列第 (1 - 置信水平) 分位数
VaR = 收益率分位数 × 持仓天数½
```

**参数法（Parametric / 方差-协方差）**:
```
μ = 历史收益率均值
σ = 历史收益率标准差
Z(95%) = 1.645, Z(99%) = 2.326
VaR = (μ - Z × σ) × √持仓天数
CVaR = VaR × 1.25
```

**输出字段**:

| 字段 | 说明 |
|------|------|
| var | VaR 绝对值（元） |
| varPercent | VaR 百分比（%） |
| cvar | 条件 VaR（CVaR，元） |
| cvarPercent | CVaR 百分比（%） |
| confidenceLevel | 置信水平（95% / 99%） |

### 3.2 波动率（Volatility）

**定义**: 年化收益率标准差，反映资产价格波动程度。

**计算公式**:
```
日收益率 = ln(今日收盘价 / 昨日收盘价)
方差 = Σ(日收益率 - 均值)² / N
年化波动率 = √(方差 × 252) × 100%
```

### 3.3 最大回撤（Max Drawdown）

**定义**: 历史最高点到最低点的最大跌幅。

**计算公式**:
```
peak = 历史最高权益
maxDrawdown = max((peak - 权益) / peak) × 100%
```

**输出字段**:

| 字段 | 说明 |
|------|------|
| maxDrawdown | 最大回撤百分比（%） |
| ddFromPrice | 回撤起始价格 |
| ddToPrice | 回撤最低价格 |
| ddDays | 回撤持续天数 |
| recoveryDays | 恢复天数 |
| currentDD | 当前回撤百分比 |

### 3.4 投资组合风险指标

| 指标 | 计算方式 | 说明 |
|------|---------|------|
| portfolioVolatility | Σ(权重 × 波动率) | 组合波动率 |
| top3Concentration | Top3 持仓权重之和 | 集中度风险 |
| diversificationScore | min(100, 100 / 持仓数量) | 分散化得分 |

## 四、仓位计算算法

### 4.1 固定比例法（Fixed Fraction）

**公式**:
```
风险金额 = 总资金 × 风险比例%
股数 = floor(风险金额 /每股风险金额 / 100) × 100
每股风险金额 = |入场价 - 止损价|
```

**参数**:

| 参数 | 默认值 | 说明 |
|------|-------|------|
| capital | 必填 | 总资金 |
| riskPercent | 2% | 单笔风险比例 |
| entryPrice | 必填 | 入场价格 |
| stopLoss | 必填 | 止损价格 |

### 4.2 凯利公式法（Kelly Criterion）

**公式**:
```
b = avgWin / avgLoss
p = winRate / 100
q = 1 - p
k = (p × b - q) / b
建议仓位比例 = max(0, min(0.25, k))
```

**特点**: 理论上最优但较激进，默认上限 25%。

### 4.3 风险平价法（Risk Parity）

**公式**:
```
目标波动率 = 风险比例% / 1.65
建议资金 = 总资金 × (目标波动率 / 资产波动率)
```

## 五、止损计算算法

### 5.1 ATR 法（默认）

**公式**:
```
TR = max(H-L, |H-PC|, |L-PC|)
ATR = ΣTR / N
止损价 = 当前价 - ATR × 倍数
```

**参数**: `atrMultiplier` 默认 2.0

### 5.2 波动率法

**公式**:
```
年化波动率 = √(收益率方差 × 252)
止损价 = 当前价 × (1 - 波动率 × 倍数%)
```

**参数**: `volatilityPercent` 默认 2%

### 5.3 均线支撑法

**公式**:
```
MA20 = 近20日收盘价均值
止损价 = MA20 × 0.98
```

### 5.4 近低法

**公式**:
```
止损价 = 近20日最低价 × 0.99
```

## 六、风险评级标准

### 6.1 单股风险评分

**公式**:
```
riskScore = (波动率 × 100 + (100 - RSI) / 2) / 150 × 100
```

**评级**:

| 风险等级 | 风险评分 | 说明 |
|---------|---------|------|
| 低风险 | 0~33 | 波动率低，RSI 适中 |
| 中风险 | 33~66 | 波动率中等 |
| 高风险 | 66~100 | 波动率高或 RSI 极端 |

### 6.2 告警阈值设置

| 指标 | 告警阈值 | 说明 |
|------|---------|------|
| RSI | >70 或 <30 | 超买/超卖 |
| 波动率 | >30% | 高波动 |
| 集中度 | >50%（Top3） | 集中度过高 |
| VaR | >5%（日） | 高风险价值 |

## 七、风险告警触发机制

### 7.1 告警类型

| 告警类型 | 触发条件 | 说明 |
|---------|---------|------|
| RSI 超买 | RSI > 70 | 价格过高，可能回调 |
| RSI 超卖 | RSI < 30 | 价格过低，可能反弹 |
| 高波动告警 | 年化波动率 > 30% | 价格波动剧烈 |
| 集中度告警 | Top3 权重 > 50% | 组合过于集中 |
| VaR 告警 | VaR > 5% / 日 | 单日可能损失超 5% |
| 回撤告警 | 当前回撤 > 20% | 需关注止损 |

### 7.2 风险热力图

实时展示市场高风险股票，基于波动率和 RSI 计算风险评分：

```
风险评分 = (波动率 × 100 + (100 - min(100, max(0, RSI))) / 2) / 150 × 100
```

颜色映射: 绿色（低风险）→ 黄色（中风险）→ 红色（高风险）
