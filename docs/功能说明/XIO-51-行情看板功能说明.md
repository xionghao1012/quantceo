# 行情看板功能说明

## 一、功能概述

行情看板是 QuantCEO 系统的首页模块，面向 OSS 免费用户，提供全 A 股实时行情浏览、搜索和排序功能。

**页面路径**: `/`（首页）
**访问权限**: OSS 用户可直接访问

---

## 三、数据源与缓存机制

### 3.1 数据源

行情数据来自两个实时接口：

**腾讯行情接口**（主用）
```
http://qt.gtimg.cn/q=s_股票代码
```
- 返回格式：`v_股票代码=字段1~字段2~...~字段N`
- 字段 [3]=现价，字段 [4]=涨跌额，字段 [5]=涨跌幅，字段 [6]=成交量，字段 [9]=成交额

**东方财富热门板块接口**（用于板块行情）
```
https://push2.eastmoney.com/api/qt/clist/get?fs=m:90+t:2
```

### 3.2 三级缓存机制

```
┌─────────────────────────────────────────────┐
│  Level 1: Redis 缓存                          │
│  Key: quotes:latest                          │
│  TTL: 30 秒                                  │
│  存储: 全市场最新行情 JSON                     │
├─────────────────────────────────────────────┤
│  Level 2: PostgreSQL klines 表                │
│  存储: 日 K 线数据（收盘价作为当日行情）         │
│  用途: Redis 未命中时降级                      │
├─────────────────────────────────────────────┤
│  Level 3: 外部 API（Sina/腾讯）               │
│  触发: DB 中无数据时主动抓取                   │
│  限制: 频率控制，避免触发限流                  │
└─────────────────────────────────────────────┘
```

### 3.3 缓存更新策略

| 缓存类型 | TTL | 更新触发 |
|---------|-----|---------|
| 全市场行情 (quotes) | 30 秒 | Redis 自然过期后下次请求触发重建 |
| 单股 K 线数据 | 2 小时 | Redis 自然过期 |
| 分钟 K 线 | 1 小时 | Redis 自然过期 |

## 四、核心 API 接口

### 4.1 获取全市场行情

```
GET /api/stocks/quotes
```

**响应示例**:
```json
{
  "600519": { "price": 1850.00, "change": 2.35, "volume": 1234567 },
  "000858": { "price": 280.50, "change": -1.20, "volume": 987654 }
}
```

**流程**:
1. 先查 Redis `quotes:latest`
2. 命中则直接返回
3. 未命中则查询 PostgreSQL `klines` 表取最新收盘价
4. 计算涨跌幅（对比前一交易日收盘价）
5. 写入 Redis（TTL=30s）后返回

### 4.2 批量获取指定股票行情

```
POST /api/stocks/quotes/batch
Body: { "codes": ["600519", "000858", "000001"] }
```

使用 PostgreSQL Lateral Join 优化， single query 获取多只股票行情。

### 4.3 获取大盘指数

```
GET /api/market/indices
```

**响应示例**:
```json
{
  "indices": [
    { "code": "sh000001", "name": "上证指数", "price": 3285.67, "change": 15.32, "changePct": 0.47 }
  ],
  "marketDate": "2026-07-22",
  "updatedAt": "2026-07-22T14:30:00.000Z"
}
```

### 4.4 获取热门板块

```
GET /api/market/hot-sectors
```

**响应示例**:
```json
{
  "sectors": [
    { "code": "BK0001", "name": "半导体", "changePct": 3.45, "mainForceInflow": 1234567890 }
  ],
  "updatedAt": "2026-07-22T14:30:00.000Z"
}
```

## 五、量化指标说明

### 5.1 涨跌幅计算

```
涨跌幅 = (当前价 - 前收盘价) / 前收盘价 × 100%
涨跌额 = 当前价 - 前收盘价
```

前收盘价取自 `klines` 表中该股票最近一条 K 线记录的 `close` 字段。

### 5.2 成交量统计

- **成交量**: 当日累计成交股数（单位：股）
- **成交额**: 当日累计成交金额（单位：元）

数据来源于腾讯行情接口字段 [6] 和 [9]。

### 5.3 市场状态缓存

`/api/market/state` 接口独立缓存，TTL=5分钟，避免频繁调用 AI 分析接口。

## 六、关键机制细节

### 6.1 实时行情抓取逻辑

```
1. 前端页面加载或下拉刷新
2. 请求 /api/stocks/quotes
3. Redis 缓存命中（TTL=30s）→ 直接返回
4. Redis 未命中 → 查询 PostgreSQL → 计算涨跌幅 → 写入 Redis → 返回
```

### 6.2 股票列表展示字段

| 字段 | 来源 | 说明 |
|------|------|------|
| code | stocks 表 | 股票代码 |
| name | stocks 表 | 股票名称 |
| price | klines.close | 最新价（当日收盘价） |
| change | 计算得出 | 涨跌幅百分比 |
| volume | 腾讯接口 | 当日成交量 |

### 6.3 数据更新频率

| 数据类型 | 更新频率 | 说明 |
|---------|---------|------|
| 实时行情 | < 1 秒 | 腾讯/Sina 接口推送 |
| Redis 缓存 | 30 秒 | 防止频繁穿透到 DB |
| K 线数据 | 交易日 18:00 | 日终更新 |

---

## 七、已知限制

1. **数据延迟**: 腾讯/新浪行情接口存在理论 < 1 秒延迟，午盘休市期间（11:30-13:00）数据停止更新
2. **缓存穿透**: 首日上市新股或数据缺失股票可能无行情显示
3. **频率限制**: 外部 API 有请求频率限制，高并发场景依赖 Redis 缓存保护
