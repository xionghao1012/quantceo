# 信号扫描规则机制说明

## 一、功能概述

信号扫描引擎对全市场股票进行技术指标扫描，识别符合条件的交易信号，支持 10 种内置策略规则。

**页面路径**: `/scan`
**访问权限**: OSS 用户可直接访问
**扫描时间**: 交易日 18:30 自动执行

---

## 二、扫描引擎架构

### 2.1 核心组件

```
┌─────────────────────────────────────────────────────┐
│                   Scheduler                         │
│            cron.schedule('30 18 * * 1-5')           │
└─────────────────┬───────────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────────┐
│              Worker Thread Pool                     │
│         Promise.allSettled (并行计算)               │
│              批量大小: 50 只股票/批                  │
└─────────────────┬───────────────────────────────────┘
                  │
    ┌─────────────┼─────────────┐
    ▼             ▼             ▼
┌────────┐  ┌────────┐  ┌────────┐
│ Worker │  │ Worker │  │ Worker │
│  线程1  │  │  线程2  │  │  线程N  │
└────────┘  └────────┘  └────────┘
```

### 2.2 扫描流程

```
1. Scheduler 触发（交易日 18:30）
2. 分批处理股票列表（每批 50 只）
3. 并行计算每只股票的指标（MA、MACD、RSI）
4. 遍历 10 种策略规则，检测信号
5. 汇总结果，更新数据库，发送推送
```

## 三、指标计算公式

### 3.1 移动平均线 (MA)

```
MA(period) = Σ(close[i]) / period
```

| 指标 | 周期 | 用途 |
|------|------|------|
| MA5 | 5 日 | 短期趋势 |
| MA10 | 10 日 | 中期趋势 |
| MA20 | 20 日 | 中长期趋势 |
| MA60 | 60 日 | 长期趋势 |

### 3.2 MACD

```
EMA12 = EMA(close, 12)
EMA26 = EMA(close, 26)
DIF = EMA12 - EMA26
Signal = EMA(DIF, 9)
MACD 柱 = DIF - Signal
```

**标准参数**: 12, 26, 9

### 3.3 RSI

```
RSI = 100 - (100 / (1 + RS))
RS = avgGain / avgLoss
```

**标准参数**: 周期 = 14
**超卖阈值**: < 30
**超买阈值**: > 70

### 3.4 成交量比

```
volRatio = 今日成交量 / 20 日平均成交量
```

### 3.5 涨跌幅

```
changePct = (今收盘价 - 昨收盘价) / 昨收盘价 × 100%
```

## 四、10 种内置策略规则

### 策略 1: MA5/20 金叉/死叉

| 方向 | 强度 | 触发条件 |
|------|------|---------|
| **金叉（买入）** | 70 | `prev.ma5 ≤ prev.ma20 AND cur.ma5 > cur.ma20` |
| **死叉（卖出）** | 70 | `prev.ma5 ≥ prev.ma20 AND cur.ma5 < cur.ma20` |

**逻辑**: 短期均线穿越长期均线，表示趋势转换。

### 策略 2: MA10/60 金叉/死叉

| 方向 | 强度 | 触发条件 |
|------|------|---------|
| **金叉（买入）** | 80 | `prev.ma10 ≤ prev.ma60 AND cur.ma10 > cur.ma60` |
| **死叉（卖出）** | 80 | `prev.ma10 ≥ prev.ma60 AND cur.ma10 < cur.ma60` |

**逻辑**: 中长期均线交叉，信号更强（强度 80 vs 70）。

### 策略 3: MACD 金叉/死叉

| 方向 | 强度 | 触发条件 |
|------|------|---------|
| **金叉（买入）** | 60 | `prev.macd ≤ prev.macdSignal AND cur.macd > cur.macdSignal` |
| **死叉（卖出）** | 60 | `prev.macd ≥ prev.macdSignal AND cur.macd < cur.macdSignal` |

**逻辑**: DIF 从下方穿越 Signal 线。

### 策略 4: RSI 超卖/超买

| 方向 | 强度 | 触发条件 |
|------|------|---------|
| **超卖（买入）** | 50 | `cur.rsi < 30` |
| **超买（卖出）** | 50 | `cur.rsi > 70` |

**逻辑**: RSI 低于 30 表示超卖可能反弹，高于 70 表示超买可能回调。

### 策略 5: MACD 零轴下方金叉

| 方向 | 强度 | 触发条件 |
|------|------|---------|
| **金叉（买入）** | 75 | `cur.macd < 0 AND prev.macd ≤ prev.macdSignal AND cur.macd > cur.macdSignal` |

**逻辑**: 在零轴下方发生的金叉，表示从空头转向多头，强度 75。

### 策略 6: 放量突破

| 方向 | 强度 | 触发条件 |
|------|------|---------|
| **放量突破（买入）** | 65 | `cur.volRatio > 1.5 AND cur.changePct > 2` |

**逻辑**: 成交量放大 1.5 倍以上且涨幅超过 2%，表示资金介入。

## 五、信号强度说明

信号强度（strength）代表策略的可靠性评分：

| 强度范围 | 含义 |
|---------|------|
| 80 | 长期趋势确认信号，最可靠 |
| 70-75 | 中期趋势信号，较可靠 |
| 60-65 | 短期信号，可能反复 |
| 50 | 反转试探信号，需结合其他指标 |

## 七、自定义规则

除内置策略外，支持自定义规则扫描：

```typescript
interface CustomRule {
  id: string
  name: string
  direction: 'BUY' | 'SELL'
  strength: number
  check: (current, previous) => boolean
}
```

用户可通过 `scanStock(code, name, klines, customRules)` 传入自定义规则。
