# 市场状态功能说明

## 一、功能概述

市场状态模块展示整体市场行情走势，包含大盘指数实时数据、热门板块排行，以及 AI 市场状态分析（Pro）。

**页面路径**: `/market-state`
**访问权限**: OSS 用户可直接访问

---

## 二、大盘指数

### 2.1 监控的指数

| 代码 | 名称 | 简称 |
|------|------|------|
| sh000001 | 上证指数 | 上证 |
| sz399001 | 深证成指 | 深证 |
| sz399006 | 创业板指 | 创业板 |
| sh000300 | 沪深300 | 沪深300 |
| sh000688 | 科创50 | 科创50 |

### 2.2 指数数据来源

腾讯行情接口实时获取：
```
http://qt.gtimg.cn/q=s_股票代码
```

**返回字段解析**:
| 字段索引 | 内容 |
|---------|------|
| 3 | 现价 |
| 4 | 涨跌额 |
| 5 | 涨跌幅 |
| 6 | 成交量 |
| 9 | 成交额 |

## 三、热门板块

### 3.1 数据来源

东方财富行业板块数据：
```
https://push2.eastmoney.com/api/qt/clist/get?fs=m:90+t:2&fields=f12,f14,f3,f62,f184,f66,f70
```

### 3.2 板块字段

| 字段 | 说明 |
|------|------|
| f12 | 板块代码 |
| f14 | 板块名称 |
| f3 | 涨跌幅 |
| f62 | 主力净流入 |
| f184 | 领涨股票代码 |
| f66 | 领涨股票名称 |
| f70 | 领涨股票涨跌幅 |

## 四、AI 市场状态分析 (Pro)

### 4.1 分析维度

AI 市场状态分析综合以下维度判断当前市场走势：

| 维度 | 说明 |
|------|------|
| 指数涨跌 | 上证/深证/创业板/科创50 涨跌幅 |
| 板块轮动 | 热门板块切换情况 |
| 成交量变化 | 市场整体成交量变化 |
| 趋势强度 | MACD/RSI 指标综合判断 |

### 4.2 市场状态分类

| 状态 | 条件 | 说明 |
|------|------|------|
| 强势上涨 | 多个指数涨幅 > 2% | 牛市行情 |
| 温和上涨 | 多个指数涨幅 0.5%~2% | 稳步上行 |
| 震荡整理 | 指数涨跌互现 | 横盘整理 |
| 温和下跌 | 多个指数跌幅 0.5%~2% | 调整行情 |
| 弱势下跌 | 多个指数跌幅 > 2% | 熊市行情 |

## 五、API 接口

### 5.1 获取大盘指数

```
GET /api/market/indices
```

**响应**:
```json
{
  "indices": [
    {
      "code": "sh000001",
      "name": "上证指数",
      "shortName": "上证",
      "price": 3285.67,
      "change": 15.32,
      "changePct": 0.47,
      "volume": "123456789",
      "turnover": "9876543210"
    }
  ],
  "marketDate": "2026-07-22",
  "updatedAt": "2026-07-22T14:30:00.000Z"
}
```

### 5.2 获取热门板块

```
GET /api/market/hot-sectors
```

**响应**:
```json
{
  "sectors": [
    {
      "code": "BK0001",
      "name": "半导体",
      "changePct": 3.45,
      "mainForceInflow": 1234567890,
      "leaderCode": "600584",
      "leaderName": "长电科技",
      "leaderChange": 5.23
    }
  ],
  "updatedAt": "2026-07-22T14:30:00.000Z"
}
```

### 5.3 获取市场状态

```
GET /api/market/state?index=000300
```

**响应**:
```json
{
  "state": "bullish",
  "stateLabel": "强势上涨",
  "indices": [...],
  "analysis": "当前市场多头格局明显，沪深300站稳均线系统...",
  "updatedAt": "2026-07-22T14:30:00.000Z"
}
```

## 六、缓存机制

| 接口 | 缓存 TTL | 说明 |
|------|---------|------|
| /api/market/indices | 实时 | 无缓存，每次请求直接抓取 |
| /api/market/hot-sectors | 实时 | 无缓存 |
| /api/market/state | 5 分钟 | 避免频繁调用 AI 分析 |
