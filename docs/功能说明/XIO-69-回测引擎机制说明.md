# 回测引擎机制说明

## 一、功能概述

回测引擎为量化策略提供历史表现评估，支持内置策略选择、自定义参数配置和资金曲线计算，帮助用户验证策略有效性。

**页面路径**: `/backtest`
**访问权限**: OSS 用户可直接访问

## 二、交易成本计算

### 2.1 费率参数

| 费用类型 | 费率 | 收取方式 |
|---------|------|---------|
| 佣金 | 0.025% | 双向（买入、卖出均收取） |
| 印花税 | 0.1% | 仅卖出时收取 |
| 滑点 | 0.1% | 买卖时价格偏移，买入上浮，卖出下浮 |

### 2.2 成本扣除顺序（卖出时）

```
1. 滑点损耗：卖出价 × (1 - slippage)
2. 佣金：成交金额 × commissionRate
3. 印花税：成交金额 × stampTaxRate
4. 成本本金：买入成本
5. 净利润 = 卖出净收入 - 佣金 - 印花税 - 成本本金
```

### 2.3 买入计算

```
滑点调整后买入价 = 买入价 × (1 + slippage)
成交金额 = 买入股数 × 调整后买入价
佣金 = 成交金额 × commissionRate
```

### 2.4 卖出计算

```
滑点调整后卖出价 = 卖出价 × (1 - slippage)
卖出净收入 = 卖出股数 × 调整后卖出价
佣金 = 卖出净收入 × commissionRate
印花税 = 卖出净收入 × stampTaxRate
净利润 = 卖出净收入 - 佣金 - 印花税 - 成本本金
```

## 三、量化指标计算公式

### 3.1 总收益率

```
总收益率 = (最终权益 - 初始资金) / 初始资金 × 100%
```

### 3.2 年化收益率

```
年化收益率 = 总收益率 × (252 / 交易天数)
```

其中 252 为年化交易日系数。

### 3.3 夏普比 (Sharpe Ratio)

```
夏普比 = (日均收益率 / 日收益率标准差) × √252

日均收益率 = Σ(日收益率) / 交易天数
日收益率 = (当日权益 - 前日权益) / 前日权益
```

### 3.4 最大回撤 (Max Drawdown)

```
最大回撤 = max((历史最高点 - 当前点) / 历史最高点 × 100%)
```

遍历权益曲线，记录历史最高点，计算每个时点的回撤，取最大值。

### 3.5 胜率

```
胜率 = 盈利交易次数 / 总交易次数 × 100%
```

### 3.6 策略综合评分

```
策略评分 = 年化收益率 × 0.25 + 夏普比 × 25 - 最大回撤 × 0.2 + 胜率 × 20
```

**注意**：交易次数 < 5 的策略不参与评分。

## 四、回测引擎架构

### 4.1 核心流程

```
for 每个交易日 date:
    1. 获取当日评分排名前 (topN + 现有持仓数) 的股票
    2. 遍历现有持仓：
       - 持有天数 >= holdingDays → 卖出
       - 条件不再满足 → 卖出
    3. 计算可用仓位 = topN - 当前持仓数
    4. 按评分权重分配资金，买入新股票
    5. 计算当日总权益，记录权益曲线
```

### 4.2 买入逻辑

```
按评分权重分配资金：allocateCapital = (cash × candidate.score) / totalScore
按手整买（100 股为 1 手）：maxShares = floor(allocateCapital / buyPrice / 100) × 100
滑点调整：buyPrice = entryPrice × (1 + slippage)
```

### 4.3 卖出逻辑

```
滑点调整：sellPrice = exitPrice × (1 - slippage)
现金增加：cash += proceeds - commission - tax
```
